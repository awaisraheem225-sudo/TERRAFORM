# TERRAFORM — Planetary Analog Intelligence

TERRAFORM is a geospatial research platform exploring measurable terrain similarities between Earth and planetary environments.

## Research scope
- Earth observation and terrestrial terrain analysis
- Mars and Moon elevation datasets
- Regional planetary analogue investigation
- Terrain comparison and candidate visualisation

## Technology
Python | Streamlit | GeoPandas | Rasterio | Pandas | NumPy | Plotly | Folium

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

This repository contains the dashboard and its pre-generated research outputs.
Large source datasets are maintained separately from the deployment repository.
